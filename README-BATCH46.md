# Batch 46 — 離線資料包完整性驗證與安全安裝

版本：`1.1.0-b46`

## 本批實作
- 新增 `js/offline-package-integrity.js`：驗證 manifest 必要欄位、檔案路徑、重複路徑、檔案大小、SHA-256 格式、總容量及檔案清單摘要。
- 安裝流程改為逐一下載 manifest 指定的真實本機資料檔，核對實際位元組數與 SHA-256；不再只對「檔案路徑清單」做模擬下載。
- 只有所有檔案驗證成功後才會寫入已驗證資料包記錄；更新失敗不會先刪除舊的穩定版本。
- 拒絕空檔、示範雜湊值、錯誤大小、錯誤摘要、HTTP 失敗與不安全路徑。
- 更新下載暫停／恢復操作，避免重複啟動下載；將新驗證模組加入 Service Worker precache。
- 更新 `data/package-manifest.json`，使用 7 個實際存在的本機 JSON 資料檔及其 SHA-256。

## 重要限制
- 本批資料包為現有應用程式 JSON 資料的離線封裝；不代表已提供完整全台向量底圖／MBTiles、全台道路圖資或即時交通服務。
- SHA-256 可偵測檔案與清單內容不一致，但若 manifest 本身來自不可信來源，單靠雜湊不能證明發布者身分；正式商用需再加入可信簽章、HTTPS 發布與金鑰管理。
- 未在真實瀏覽器、實體手機或實際 GPS 裝置完成驗收。
- Batch 19–34 的部分歷史修改仍未恢復。
