# Batch 45 — 導航狀態機與非同步偏航重算競態防護

版本：`1.1.0-b45`

## 本批實作
- 新增導航狀態轉移規則查詢 `isNavigationTransitionAllowed()`，明確描述導航中、GPS 失訊、偏航、抵達與路線待命狀態之合法轉移。
- 導航開始、停止、GPS 失訊、抵達及引擎銷毀時更新導航世代識別值；非同步偏航重算回傳後必須仍屬於同一個有效導航世代。
- 偏航重算結果套用前，重新檢查導航狀態、GPS 可靠度、原路線指紋及目的地；避免舊結果覆蓋停止導航、GPS 失訊、抵達或更新後路線。
- 偏航重算失敗時，也只會在原導航仍有效時切換至 `OFF_ROUTE`。
- 更新 Service Worker 快取版本及目前版本契約測試。
