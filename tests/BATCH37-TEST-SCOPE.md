# Batch 37 — 使用者流程契約測試範圍

## 自動化檢查（原始碼契約）
- 搜尋按鈕與 Enter 鍵觸發離線搜尋
- 選取結果更新目的地並顯示地圖圖釘
- 規劃、替代路線與清除路線事件處理器存在
- 開始/停止導航會呼叫導航引擎與 GPS 控制器
- 離線時禁止發起資料包下載請求
- online/offline 事件更新網路狀態
- Service Worker 快取版本、離線 fallback、預快取檔案存在

## 尚未實測（不能標記為通過）
- 真實 Chromium/Firefox/Safari 瀏覽器渲染與點擊
- Android/iOS 真機、定位權限與 GPS 精度
- 真正斷網後重新整理、首次安裝快取及更新版本遷移
- 真實地圖、道路導航、語音與即時交通服務

本批次測試是 source-level contract checks，不等同於端到端瀏覽器測試或道路實測。
