# AI GPS 導航系統 — Batch 59

版本：`1.1.0-b59`

## 本批目標：離線路網資料與輸入驗證

- 新增 `validateRoutingGraph(graph)`，在載入靜態路網或已驗證離線資料包中的路網後，檢查節點 ID 是否缺失／重複、座標是否有效、道路邊端點是否存在，以及距離與通行時間是否為正有限數值。
- `OfflineRouter.calculate()` 現在會在載入資料前檢查起點、目的地及途經點座標，並在規劃前確認路網含有可用節點。
- 無效路網在被接受前即會拒絕，避免損壞資料進入路線計算。
- 更新 `VERSION` 與 Service Worker 快取名稱至 `1.1.0-b59`。

## 已知限制

內建道路與 POI 仍為示範資料，尚不足以宣稱具備全台完整商用地圖覆蓋。Node.js 自動化測試不取代實機驗收。
